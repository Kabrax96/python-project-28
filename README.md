# Python_project_28

Web application with a Python backend, a frontend, and a relational database.

## Project Structure

- `backend/` — API, data models, and business logic
- `frontend/` — User interface
- `database/` — Schema, migrations, and seed data
- `docs/` — Project documentation

## Setup

```bash
git clone https://github.com/<USER>/Python_project_28.git
cd Python_project_28
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
